# 오너사이드 (OwnerSide) — 발주자 편 IT 프로젝트 파트너 · 랜딩

개인 신규사업 '발주자 편 IT 프로젝트 PM 서비스'의 원페이지 랜딩. 확정 콘텐츠 덱을 충실히 렌더한 정적 사이트.

- **공개 URL**: https://insightjung27.github.io/ownerside-landing/
- **구조**: 단일 HTML(`index.html`) + 모달(팝업) + `app.js` + `styles.css` + 결정론 토큰(`tokens.css`)
- **디자인 토큰**: `web_starter_kit/generate_tokens.py`로 생성(씨앗 딥네이비 #0F2A4A · accent 레드 #E23B3B · 배경 화이트). 수기 수정 금지 — 씨앗값만 바꿔 재생성.
- **팔레트(덱 확정)**: 본문 차콜 #1A1D23 / 포인트 딥네이비 #0F2A4A / accent 레드 절제 / 보조 그레이 #5B6472 / 라인 #EEF1F5. `styles.css` 상단에서 시맨틱 변수 재지정으로 반영(컴포넌트 hex 하드코딩 없음).
- **폰트**: Pretendard (CDN 1개).
